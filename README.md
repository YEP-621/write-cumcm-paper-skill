# write-cumcm-paper

面向全国大学生数学建模竞赛（CUMCM/国赛）的中文 XeLaTeX 论文写作、修改与提交前验收 skill。

## 能做什么

- 将已确认的题面、建模方案、真实计算结果、代码和图表组织为国赛论文。
- 修改既有 LaTeX 论文，改善论证、章节结构、公式符号、图表与版式。
- 按现行国赛规范检查匿名性、页数、参考文献、AI 披露、交叉引用、图表和结果一致性。

## 写作原则

- 仅支持中文 CUMCM 的 XeLaTeX 论文，不用于 Word、Typst 或其他竞赛。
- 写作前必须形成可写性报告和“主张—证据”矩阵；结果、参数或结论缺乏依据时应停止补写，而不是虚构。
- 每个子问题突出主模型，算法说明覆盖机制、参数、求解与检验；创新须有不足、改进、合理性和定量证据链。
- 采用匿名、无目录的固定国赛结构：摘要、问题描述、逐问分析、少量模型假设、三线表定义与符号说明、逐问建模求解、模型评价、单独分页的参考文献及附录。
- 关键词固定为五个；重要符号放入三列表，未列符号在首次公式后以“其中，……”说明；同类图片统一尺寸并保证清晰。

## 目录

- `assets/latex-template/`：XeLaTeX 论文模板。
- `references/`：格式合规、写作、算法创新与视觉排版参考。
- `scripts/init_paper.py`：初始化分章节论文工程。
- `scripts/audit_paper.py`：输出提交前质量审查报告。

官方规则可能更新；实际提交前仍应以当年 CUMCM 官方要求为准。
